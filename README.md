# Sistema de Inventario Full Stack

Proyecto académico desarrollado como continuación del sistema de inventario creado durante la asignatura de Desarrollo Back-End.

## Objetivo

El proyecto busca facilitar la organización y gestión de insumos mediante un sistema de inventario que permite estructurar productos según sus categorías y registrar su stock disponible.

## Estructura del proyecto

### Backend

El Backend fue desarrollado utilizando:

- Python
- Django
- Django REST Framework
- SQLite

Incluye los modelos, la base de datos y la API REST desarrollados durante la asignatura anterior.

### Frontend

El prototipo de interfaz fue desarrollado utilizando:

- HTML
- CSS
- JavaScript

Incluye las siguientes pantallas:

- Inicio
- Productos
- Categorías
- Agregar producto

## Estado actual

Actualmente, el proyecto cuenta con un Backend desarrollado previamente y un prototipo funcional de interfaz Front-End. La integración directa entre ambas partes corresponde a una posible etapa posterior del desarrollo.
